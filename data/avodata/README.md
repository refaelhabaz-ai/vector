# קובצי האיסוף מעבודאטה

כאן מניחים את הקובץ `avodata-dump-<תאריך>.zip` שהסקריפט `tools/avodata-collect.console.js` שמר בדפדפן (ההוראות בראש הסקריפט וב-`tools/README.md`),
ומשם קוראים אותו עם `node tools/verify-avodata.mjs data/avodata/avodata-dump-<תאריך>.zip`.

הקבצים האלה הם דפי עבודאטה כפי שנקראו, לא נתונים של האתר: הם נקראים ואינם מתפרסמים. לכן `.gitignore` לא מוסיף אותם בטעות,
ומי שהעלה קובץ ידנית מוחק אותו מהעץ אחרי שנבדק, כדי שהוא לא יוגש עם האתר (האתר מוגש מהשורש של המאגר).
