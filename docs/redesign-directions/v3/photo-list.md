# רשימת תמונות לאבות-הטיפוס (v4)

**למה יש כאן רשימה ולא תמונות:** בסביבה שבה אני עובד לא הצלחתי לחפש תמונות ב-Unsplash או ב-Pexels. הגישה לחיפוש הפנימי של Unsplash נחסמה, ולא ניסיתי לעקוף את החסימה. בלי חיפוש אין לי דרך לבחור תמונה מתאימה ולדעת מי הצלם שלה, ולכן לא הכנסתי תמונות "על עיוור". בינתיים כל מקום לתמונה מסומן בבירור (`TODO: תמונה · photos/<קובץ>.webp`), והעמוד מציג אותו בצבע העולם.

## איך מכניסים תמונה
1. מורידים תמונה חופשית (Unsplash License או Pexels License, בלי חיוב בייחוס, אבל מתעדים בכל זאת).
2. ממירים ל-WebP, **עד 150KB**, ברוחב 1600px לתמונות רחבות ו-1000px לשאר. למשל: `cwebp -q 78 -resize 1600 0 in.jpg -o out.webp`.
3. שומרים ב-`docs/redesign-directions/v3/photos/` בשם המדויק שבטבלה. **ברגע שהקובץ שם, התמונה מחליפה את החריץ לבד** (בלי שינוי קוד).
4. מוסיפים שורה ל-`docs/photo-credits.md`: קובץ, קישור לדף התמונה, שם הצלם, רישיון.

## כללים לבחירת תמונות
- אנשים לומדים או עובדים בתחום, צעירים, מודרני, חי וצבעוני.
- **אסור שתמונה תרמוז על סיפור, עדות או אדם מסוים** ("סטודנטית שלמדה אצלנו"). נשארים עם סצנה כללית.
- אנשים בקבוצה או בעבודה עדיפים על פורטרט מביט למצלמה. אור טבעי. בלי לוגואים או טקסט קריא בתמונה.
- יחס: hero ותואר 4:5, כרטיסי עולם ותוצאות 4:3 או 16:10 (החריץ חותך לבד).
