# אבות-טיפוס v3: "לבן, פרימיום, חי"

מבוסס על `docs/vector-design-brief-v3.md`. **`index.html` לא שונה.** אלה קבצי HTML עצמאיים (בלי build), עם תוכן אמיתי מהאתר.

## איך רואים
פותחים `home.html` בדפדפן. בפס העליון (שחור, אפשר להסתיר עם `?bar=0`) עוברים בין המסכים, בין וריאציה A (רגוע) ל-B (שובב), ובין שני זוגות הגופנים.
אפשר גם בכתובת: `home.html?v=a|b&font=rubik|secular`. המסכים: `home.html`, `degree.html` (פסיכולוגיה), `quiz.html` (שאלה אחת), `results.html`.

## מבנה
- `v3.css`: כל העיצוב (טוקנים בראש הקובץ: סקאלות 50–900 לארבעת צבעי הנוצות, סקאלת ריווח של 8, שבע גדלי טקסט, רדיוס 12px, צל אחד).
- `fonts.css`: Rubik, Heebo ו-Secular One (רישיון SIL OFL 1.1, אותם קבצים שהיו מוטמעים באתר).
- `screens/`: צילומי מסך ב-1440 וב-390 (`<מסך>-<a|b>-<rubik|secular>-<d|m>.jpg`, וגרסת `-full` לעמוד מלא).

## ההבדל בין A ל-B
**A, רגוע:** דף לבן, הצבע בכרטיסי העולמות, בוקטי ובהדגשות. תנועה: טעינה אחת מתוזמרת (הכותרת, ה-CTA והחיפוש עולים בהדרגה, בועת וקטי קופצת), הרמה של 4px בכרטיס עולם בריחוף, לחיצה על כפתור יורדת פיקסל, עמודות השכר גדלות, מילוי סרגל השאלון.
**B, שובב:** כל מה ש-A עושה, ובנוסף: פס 4 הצבעים העבה מתחת ל-hero, וקטי גדול שצף, בועת דיבור צהובה, אייקוני עולם עגולים שמסתובבים בריחוף, ארבעה פסי צבע במסך הבית (תואר, פורום, סיפורים, מלגות) כל אחד בצבע העולם שלו, וקטי מציץ מקצה פס, מספרי "איך זה עובד" בצבעי הנוצות, כותרות פרקים עם אייקון עגול ופרקים בגוון כחול בדף התואר, חשיפה עדינה בגלילה (פעם אחת), פס התקדמות בארבעת הצבעים עם וקטי שמתקדם עליו, וקטי קופץ ו-16 פיסות קונפטי בתוצאות (ב-A: 8).
כל התנועה: 150–800ms, ease-out, CSS בלבד (פלוס `IntersectionObserver` קטן לחשיפה ב-B), ומבוטלת כולה תחת `prefers-reduced-motion`.

## בדיקות
- Lighthouse accessibility: **100** בכל ארבעת המסכים בשתי הווריאציות (דסקטופ).
- ללא שגיאות קונסול וללא גלילה אופקית ב-1440 וב-390.
- ניגודיות: טקסט ראשי 15.6:1, משני 9.2:1, שלישוני 5.8:1, לבן על כתום 5.2:1, כחול 700 על לבן 9.5:1, ירוק 700 על לבן 5.1:1. צהוב משמש רק כרקע (כרטיס, אייקון, פס), לא כטקסט.
