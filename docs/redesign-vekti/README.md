# וקטי החדש (תצוגה מקדימה, לא באתר)

אותו תוכי ארה אדום, זקוף וערני. **עדיין לא הוחלף באתר:** מחכה לאישור.

- `old-vs-new.png`: הנוכחי מול החדש (ברירת מחדל, מצביע ומסביר, חוגג, בטיסה, פונה לצד השני, ובגודל קטן).
- `vekti_new.js`: ה-SVG החדש (`vfSVG2`, עם אותם מחלקות של הקיים: `vf-pose`, `vf-head`, `vf-jaw`, `vf-lid`, `vf-w`...) ושלוש תנוחות: `pose:''` ידידותי, `'point'` מצביע ומסביר, `'cheer'` חוגג.
- `vk.css`: התנועה (מצמוץ, נשימה, הטיית ראש בריחוף, נפנוף כנף בברכה, קפיצה). הכול כבוי תחת `prefers-reduced-motion`.
