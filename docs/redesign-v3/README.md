# העיצוב החדש (v3): "חי, לא מסד נתונים"

האתר נשאר קובץ אחד (`index.html`), בלי build ובלי ספריות חיצוניות (ה-CSP מתיר סקריפטים רק לפי hash, ופונטים ותמונות רק מ-`data:`).
כל מה שחדש בקוד יושב בשני בלוקים מסומנים:

| מה | איפה | סימן |
|---|---|---|
| CSS | `<style id="vector-v3">` | `/*@@V3-CSS@@*/ … /*@@V3-CSS-END@@*/` |
| JS | בסקריפט הראשי, ממש לפני האתחול | `/*@@V3-JS@@*/ … /*@@V3-JS-END@@*/` |

אחרי כל עריכה בסקריפט צריך לעדכן את ה-hash ב-CSP: `node tools/csp-hash.js --write` (הכלי מטפל בשני הסקריפטים, גם של הבוט). `--check` רץ ב-CI.

## מערכת העיצוב
- **פלטה** (משתני `--v3-*`): אדום מקאו, צהוב, תכלת, ירוק, כתום וסגול, על קרם. הצבעים נבדקו ל-AA.
- **צבע לאזור:** `html[data-sec]` קובע את `--acc-fill` / `--acc-soft` / `--acc-ink`. תארים כחול, מקצועות כתום, הנדסאים ירוק, פורום צהוב, מסלול ושאלון תכלת, אזור אישי סגול, הבית אדום. `renderChrome` מציב את `data-sec`.
- **משתני הישן** (`--v-*`, `--primary`, `--r` ועוד) מומפו לחדשים, ולכן כל האתר עוקב.
- **תנועה:** transform ו-opacity בלבד. שלושה מצבים של האתר (`html.rg` עדין, `html.rm` כבוי) ובנוסף `prefers-reduced-motion` בכל הרכיבים החדשים. אסור להשאיר `transform` ב-`fill-mode: forwards` על מכולה (זה הופך אותה לבלוק מכיל של אלמנטים קבועים).

## רכיבים
- **וקטי:** `vfSVG({perch,flip,cls,decor})` מצייר SVG עם חלקים נפרדים (כנפיים, זנב, ראש, לסת, עפעף). מצבים כמחלקות: `vf-fly`, `vf-hover`, `vf-perch`, `vf-idle`, `vf-happy`, `vf-talk`. הנוצות והקונפטי: `vfDrop`, `vfBurst`, `vfCheer`.
- **הסיור:** `vtStart`, `vtEnd`, צעדים ב-`vtSteps`. מתחיל לבד בביקור ראשון בדף הבית (תנאי: לא נראה `seenProf`/`tourSeen`), אחריו מודאל הפרופיל. כפתור "סיור עם וקטי" בתפריט, בכותרת, בנגישות ובבוט.
- **קטלוג:** `cgCats`, `cgBar`, `cgPanel`, `cgChip`, `cgHero`, `cgEmpty`. משמש תארים, מקצועות והנדסאים. המצב והאירועים הם הישנים (`S.cat`, `S.f`, `JOBF`, `TF`, `data-fset`, `data-fopen`).
- **עמודי פרט:** `dpTabsInit` ממיין את הבלוקים הקיימים ללשוניות אחרי הציור (`dpClassify`), ו-`dpBar` בונה שורת פעולות דביקה בנייד.
- **מסלול:** `smScene`, `smTrail`, ו-`CAR_SVG` הוא וקטי. `smGeo` / `smDrive` נשארו כמו שהיו.
- **שאלון:** `vqFly` (פס עם וקטי). **פורום:** `FQOD` (60 שאלות), `fqPick` לפי התאריך בירושלים, `fDailyHTML`.

## בדיקות
`node tests/quiz-v2/all.js` מריץ את הסוויטה. ארבע בדיקות כושלות גם על `main` שלפני העיצוב ואינן קשורות: `integration` (המדף "הכי מתאימים לי" לא קיים), `stage2`, `stage4`, ו-`build-legal` (`privacy.html` ו-`terms.html` מיושנים).
