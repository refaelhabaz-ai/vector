# קובץ HTML אחד עם כל האתר

כדי לשלוח לחברים את האתר כקובץ אחד (בלי שרת ובלי תיקיות):

```bash
node tools/build-standalone.js
```

הקובץ נוצר ב-`dist/vector-standalone.html` (כ-15MB, לא נכנס ל-git). אפשר לשלוח אותו במייל, בוואטסאפ או בכונן שיתוף, ולפתוח בדפדפן בלחיצה כפולה, גם בטלפון.

מה בפנים: כל האתר כמו ב-`index.html` (נתונים, פתיחים, תקנון, נגישות, גופנים, אייקונים), כל התמונות שהאתר משתמש בהן (כתובות data:), וספריית ההתחברות (מוטמעת, ומאושרת ב-CSP לפי hash).

מה עדיין דורש אינטרנט, כמו באתר החי: התחברות עם Google והפורום (מדברים עם Supabase). בלי חיבור כל השאר עובד. ההתחברות עם Google חוזרת לכתובת האתר החי ולא לקובץ המקומי.

הכלי לא משנה את `index.html`. אחרי כל שינוי באתר מריצים אותו שוב כדי לקבל עותק עדכני.

## לקבל חזרה קובץ שעבדו עליו

כשאתה או חבר מסיימים לערוך את הקובץ ושולחים אותו חזרה:

```bash
node tools/import-standalone.js <הקובץ>            # מראה מה השתנה, בלי לגעת בריפו
node tools/import-standalone.js <הקובץ> --apply    # מעתיק ל-index.html, ואז מריצים את הבדיקות
```

הכלי מסיר את מה שהבנייה הוסיפה (טבלת התמונות וספריית ההתחברות), מחזיר את שורות התמונות וההתחברות, ומחשב מחדש את ה-hash של ה-CSP. קובץ שלא שונה יוצא זהה ל-`index.html`. אחרי היבוא: בדיקות (17 מתוך 17), בדיקת CSP, מיזוג ל-`main`, ובניית קובץ חדש.

מגבלות: שינויים בתוך טבלת התמונות או בספרייה המוטמעת לא מיובאים (תמונה חדשה נכנסת ל-`photos/` ול-`docs/photo-credits.md`). מידע שמישהו הזין באתר (פרופיל, תשובות) נשמר בדפדפן שלו ולא בקובץ, ולכן לא חוזר איתו.

## עותק לחברים, בלי חיבור לשום שרת

```bash
node tools/build-standalone.js --offline
```

כותב את `dist/vector-offline.html`: קובץ אחד עם כל האתר והתמונות, שלא מתחבר לשום מסד נתונים או שרת. ספריית ההתחברות לא נכללת, כתובת הפרויקט והמפתח הוסרו, מדיניות האבטחה של הדפדפן (`connect-src 'none'`) אוסרת כל בקשת רשת, וכפתור ההתחברות מוסתר. כל השאר עובד: תארים, מקצועות, השאלון, התוצאות, בניית מסלול, מחשבונים והפורום המקומי. מה שאנשים מקלידים נשמר רק בדפדפן שלהם.
