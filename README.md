# וקטור

אתר הכוונה ללימודים ולקריירה בישראל: תארים, מקצועות, הנדסאים וטכנאים, ספי קבלה, שכר, מלגות ומסלול אישי עד היום הראשון בלימודים.

האתר הוא קובץ אחד, `index.html`, בלי שרת ובלי שלב בנייה. הנתונים והגופנים מוטמעים בו, והמידע האישי שהמשתמש מזין נשמר בדפדפן שלו בלבד. לפתיחה מקומית פותחים את הקובץ בדפדפן.

- **נתונים ומקורות:** רשימת התארים והמוסדות מהמועצה להשכלה גבוהה, ספי קבלה מאתרי המוסדות, שכר ותעסוקה מעבודאטה (משרד העבודה). כל נתון שלא אומת מסומן ככזה, ולא מושלם בהערכה. פירוט בעמוד "תקנון" באתר.
- **כלים לאמינות ולעדכניות:** `tools/` (בדיקת עקביות של הנתונים, מעקב אחרי דפי המקור והזרקת התוצאה לאתר). ראו `tools/README.md`.
